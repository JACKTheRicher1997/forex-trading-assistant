# ⚡ Forex Trading Assistant & Alert System (ระบบผู้ช่วยเทรด Forex & แจ้งเตือนอัจฉริยะ)

ระบบผู้ช่วยเทรด Forex ครบวงจร พัฒนาด้วยภาษา **Python** ตามหลักการ **Object-Oriented Programming (OOP)** และ **Clean Architecture** พร้อมหน้าเว็บ Dashboard ธีม Dark Mode สวยงาม และระบบแจ้งเตือนเข้าสู่ LINE อัตโนมัติ

> 📖 **ต้องการคู่มือละเอียดทีละขั้นตอน?** เปิดได้ที่ [`SETUP_GUIDE.md`](SETUP_GUIDE.md) — อธิบายการทำงานของ Dashboard, บอท LINE, และวิธีตั้งค่า Secrets ทั้งใน GitHub และ Streamlit

## 🌟 จุดเด่นและฟังก์ชันการทำงานหลัก

### 1. สถาปัตยกรรมระบบ (OOP & Architecture)
- **Modular & Separation of Concerns**: แยกคลาสความรับผิดชอบอย่างชัดเจน (`PriceService`, `IndicatorService`, `ForexFactoryNewsService`, `NotificationService`, `AlertScheduler`, `TradingAssistant`)
- **Centralized Configuration**: โหลดค่า Configuration และ Secrets ผ่าน `config.py` จากไฟล์ `.env` อย่างปลอดภัย
- **Logging System**: บันทึกการทำงานทั้งบน Console และไฟล์ `bot.log` ด้วย `RotatingFileHandler` เพื่อความทนทานและตรวจสอบย้อนหลังได้ง่าย

### 2. ระบบรวบรวมข่าวแดงจาก ForexFactory (High-Impact News)
- ดึงข้อมูลปฏิทินเศรษฐกิจจาก ForexFactory API แบบเรียลไทม์
- **กรองเฉพาะข่าวสีแดง (High-Impact)** ที่ส่งผลกระทบต่อตลาดรุนแรง
- **เงื่อนไขการส่งแจ้งเตือน LINE**: ส่งสรุปภาพรวมข่าว **สัปดาห์ละ 1 ครั้ง ในทุกๆ เช้าวันจันทร์** (ก่อนตลาดเปิด)
- รายละเอียดในข้อความประกอบด้วย:
  * จำนวนข่าวสีแดงทั้งหมดในสัปดาห์นั้น
  * ข่าวแดงในแต่ละวัน (ชื่อข่าว, สกุลเงิน, เวลาที่ข่าวออกเป็นเวลาไทย)
  * **หากวันไหนไม่มีข่าวแดง**: ระบุข้อความอย่างชัดเจนว่า `"🟢 วันนี้ไม่มีข่าวสีแดง สามารถเทรดได้ตลอดวัน"`

### 3. ดึงราคาจริง (Yahoo Finance / Twelve Data) & ตรวจจับ EMA Cross
- ดึงข้อมูลราคาผ่าน **Cloud API** แทน MetaTrader 5 ทำให้ใช้งานบน **Streamlit Community Cloud ได้ฟรี**
- **เลือกแหล่งข้อมูลได้ 2 แบบ** ผ่าน `PRICE_SOURCE`:
  | ค่า | แหล่งข้อมูล | หมายเหตุ |
  |------|-----------|----------|
  | `yahoo` | Yahoo Finance (`GC=F`) | ไม่ต้องใช้ API Key |
  | `twelvedata` | Twelve Data (XAU/USD Spot) | **ตรงกับ MT5/Exness มากกว่า** (Free 800 req/วัน) |
- รองรับสัญลักษณ์หลายชนิด: XAUUSD (Gold), EURUSD, GBPUSD, USDJPY, BTCUSD ฯลฯ พร้อมแปลงชื่อสัญลักษณ์ให้อัตโนมัติตามแต่ละแหล่งข้อมูล
- คำนวณ **EMA 50** (Fast) และ **EMA 150** (Slow) บน Timeframe ที่กำหนด (M5, M15, M30, H1, H4, D1)
- **Live Signal Alert แจ้งเตือนเข้า LINE ทันทีเมื่อเกิดการตัดกัน**:
  * **EMA 50 ตัดขึ้นเหนือ EMA 150** -> ส่งแจ้งเตือนระบุว่าเป็น **"🚀 Uptrend / เทรนขาขึ้น"**
  * **EMA 50 ตัดลงใต้ EMA 150** -> ส่งแจ้งเตือนระบุว่าเป็น **"🔻 Downtrend / เทรนขาลง"**
- **Deduplication System**: มีระบบป้องกันการแจ้งเตือนซ้ำ โดยจะส่งเพียงครั้งเดียวต่อแท่งเทียนนั้นๆ
  * เก็บสถานะไว้ใน `state/ema_cross_state.json` จึง **ไม่ซ้ำแม้ข้ามรอบการทำงาน** (เช่น GitHub Actions ที่สร้าง process ใหม่ทุก 5 นาที)

### 4. คำเตือนห้ามเทรดช่วง London Session ในวันที่มีข่าวแดง (No-Trade Alert)
- ทุกวัน เวลา **14:00 น.** (เวลาไทย) ระบบจะตรวจว่าวันนี้มี**ข่าวสีแดง (High-Impact)** หรือไม่
- หากมีข่าวแดง: ส่งแจ้งเตือนเข้า LINE ทันที เตือนว่า **"🛑 อย่าพึ่งเข้าเทรด"** เพราะตลาด London จะ **Sideway** ตั้งแต่ 14:00 จนถึงเวลาข่าวจริงออก -> **โอกาสแพ้สูงมาก**
- แจ้งเตือนรายการข่าวแดงของวันนี้พร้อมเวลาออกจริง เพื่อให้รู้ว่าควรเริ่มเทรดเมื่อไหร่
- แนะนำให้ **รอข่าวจริงออกก่อน** แล้วค่อยเลือกทางเข้าเทรดตามทิศทางใหม่
- **กันส่งซ้ำ**: ส่งเพียง 1 ครั้งต่อวัน และข้ามวันเสาร์-อาทิตย์ (ไม่มีตลาด)

> 📌 ตั้งค่าผ่าน `.env`: `LONDON_ALERT_ENABLED=true` (เปิด/ปิด) และ `LONDON_ALERT_TIME=14:00` (เวลาส่งเตือน)

### 5. แจ้งเตือนผลข่าวจริงหลังข่าวแดงออก (News Release Alert)
- ระบบจะตรวจทุก **1 นาที** ว่าข่าวแดงที่สำคัญได้ออกจริงไปแล้ว **5 นาที** หรือไม่ (เช่น ข่าวออก 19:30 -> ส่งตอน 19:35)
- แจ้งเตือนเข้า LINE โดยแสดง:
  * **ชื่อข่าว** + สกุลเงิน + เวลาที่ข่าวออก
  * **ค่าจริง (Actual)** — ตัวเลขสีจริงชัดเจนใน Flex Message:
    * 🟢 **สีเขียว** = ตัวเลขจริงดีกว่าค่าคาดการณ์
    * 🔴 **สีแดง** = ตัวเลขจริงแย่กว่าค่าคาดการณ์
    * ⚪ **สีเทา** = เท่าคาด / ค่าปกติ
  * **ค่าคาดการณ์ (Forecast)** และ **ค่าก่อนหน้า (Previous)**
- กันส่งซ้ำ: ส่งเพียงครั้งเดียวต่อ 1 ข่าว (Key: วันที่+สกุล+ชื่อข่าว)
- **Fallback**: ถ้าไม่มี LINE Messaging API จะส่งเป็นข้อความตัวอักษร โดยใช้สีอีโมจิ 🟢/🔴/⚪ แทน (LINE Notify รองรับแค่ข้อความ)

> 📌 ตั้งค่าผ่าน `.env`: `NEWS_RELEASE_ALERT_ENABLED=true` และ `NEWS_RELEASE_ALERT_DELAY_MINUTES=5` (กี่นาทีหลังข่าวออกถึงจะส่ง)

> **หมายเหตุ**: ราคาที่ดึงจาก Yahoo Finance อาจไม่ตรงกับราคาจากโบรกเกอร์ (เช่น Exness) 100% เนื่องจากแหล่งข้อมูลต่างกัน และข้อมูลมี delay เล็กน้อย (ไม่ใช่ tick เรียลไทม์)

### 6. หน้าเว็บ Dashboard (Streamlit & Plotly)
- ดีไซน์สวยงามระดับ **Dark Mode Luxury Glassmorphism** ทันสมัย อ่านง่าย และรองรับการแสดงผลบนมือถือ (**Responsive**)
- **Indicator & Trend Status**:
  * แบนเนอร์เน้นสีเขียวสดใส **`CURRENT TREND: BULLISH`** หรือสีแดง **`CURRENT TREND: BEARISH`**
  * เกจวัด (Plotly Gauge) แสดงระยะห่างของเส้น EMA และโมเมนตัมของตลาด
  * กราฟ Candlestick แบบ Interactive ซูม/เลื่อนดูจุดตัดของ EMA 50 และ EMA 150 ได้ละเอียด
- **Multi-Timeframe (MTF) แบบขนาน**: สรุปเทรน M5–D1 ทั้ง 6 กรอบเวลาโหลดพร้อมกันด้วย `ThreadPoolExecutor` (เร็วกว่าโหลดทีละเฟรม) คลิกที่กล่องเพื่อสลับกรอบเวลาได้ทันที พร้อมแสดงค่า RSI ของแต่ละกรอบ
- **ชุดเครื่องมือวิเคราะห์ครบวงจร** (ดูรายละเอียดในหัวข้อถัดไป):
  * แผง Trade Verdict รวมสัญญาณข่าวแดงและเทรน MTF
  * แผงแนวรับ/แนวต้าน (S/R) จาก ATR และจุดกลับตัวตามเทรน
  * แผง DXY, RSI + Divergence, Market Structure
  * แผง ZigZag + จุดย่อเข้าตามเทรน, แผง Trading Sessions พร้อมนับถอยหลังและ Overlap
  * แผง Price Alert
- **ForexFactory News Section**:
  * **Weekly Summary**: ตารางสรุปภาพรวมข่าวแดงทั้งหมดของสัปดาห์
  * **Day Selector**: เลือกคลิกดูข่าวแดงรายวัน พร้อมแบนเนอร์แสดงวันที่ไม่มีข่าวแดง
  * **Monthly Calendar View**: ปฏิทินเลือกดูข่าวแดงย้อนหลังหรือล่วงหน้าของทั้งเดือน พร้อมระบบกรองสกุลเงิน (USD, EUR, GBP, JPY ฯลฯ)
- ปุ่มสั่งงานด่วน: กดทดสอบส่ง LINE หรือกดส่งสรุปข่าวแดงเข้า LINE ได้ทันทีผ่านหน้าเว็บ
- **โหมดรีเฟรชอัตโนมัติ**: เลือกได้ว่าจะรีเฟรชตรงแท่งเทียนปิด ทำให้ค่าทุกแผงตรงกับข้อมูลจริงเสมอ (ไม่มีแท่งที่ยังไม่ปิดปน)

## 🔬 ชุดเครื่องมือวิเคราะห์เพิ่มเติม (Dashboard Toolkit)

ทุกเครื่องมือชุดนี้คำนวณจากแท่งเทียนที่ปิดแล้วเท่านั้น (ตัดแท่งที่ยังไม่ปิดออก) จึงไม่มีค่ามั่วจากราคาที่กำลังวิ่ง

### 7. แผง DXY (US Dollar Index) — ข้อ 1
- ดึงดัชนีดอลลาร์จากแหล่งเดียวกับราคาหลัก โดยแปลงสัญลักษณ์ให้อัตโนมัติ
  * Yahoo Finance: `DXY` → **`DX-Y.NYB`**
  * Twelve Data: `DXY` → **`DXY`**
- แสดง **ราคา DXY**, **เปลี่ยนแปลงรายวัน** (พร้อมสีตามทิศ), **ระยะห่างจาก EMA** และ **แนวโน้ม**
- **หมายเหตุสำหรับทองคำ (XAUUSD)**: ระบุชัดว่า USD แข็ง → กดดันทอง / USD อ่อน → หนุนทอง (inverse relationship)
- **ค่าสหสัมพันธ์ (Correlation)**: คำนวณจากผลตอบแทนรายแท่งของ DXY เทียบกับสินทรัพย์ที่เลือก
  * `+1` = เคลื่อนไหพร้อมกัน · `-1` = เคลื่อนไหทางกลับกัน · ใกล้ `0` = ไม่มีความสัมพันธ์
  * ถ้าข้อมูลน้อยเกินไปจะแสดง "ข้อมูลไม่พอ" แทนตัวเลขที่ทำให้เข้าใจผิด
- ดึงแบบ cache (5 นาที) ไม่กินโควตา API

### 9. Custom Price Alert แจ้งเตือน LINE — ข้อ 3
- ตั้งเป้าหมายราคาเองได้ทั้ง **แตะขึ้น** และ **แตะลง** ในแถบด้านข้าง (พร้อมตัวเลือก timeframe)
- แสดง **ราคาปัจจุบัน** และ **ระยะถึงเป้า** ของแต่ละรายการแบบเรียลไทม์
- ตรวจจาก **High/Low ของแท่งล่าสุด** (ไม่พลาดแม้ราคาแตะเป้าแล้วดึงกลับในแท่งเดียว)
- **ยิงครั้งเดียว** ต่อเป้าหมาย แล้วเปลี่ยนสถานะเป็น "ยิงแล้ว" พร้อมเก็บประวัติ 20 รายการ
- ตั้งเป้าใหม่หรือยกเลิกได้ตลอด ข้อมูลเก็บที่ `state/price_alert.json`

### 9. RSI(14) + Divergence — ข้อ 3
- คำนวณ **RSI แบบ Wilder's Smoothing** ซึ่งเป็นสูตรมาตรฐานเดียวกับ TradingView (ทดสอบเทียบกับสูตรอ้างอิงแล้วตรงกันทุกแท่ง)
- **หน้าเว็บแสดง 2 ระดับ**:
  * ค่า RSI ของ **ทุกไทม์เฟรม** (M5–D1) ใต้ปุ่มสรุปเทรน พร้อมแถวสรุปรวม
  * แผงเต็มพร้อม **แถบโซนสี** และเข็มบอกตำแหน่ง พร้อมคำแนะนำเป็นภาษาไทย
- **แบ่งโซนให้อัตโนมัติ**: ≥70 สูงเกินไป (ระวังไล่ซื้อ) · ≤30 ต่ำเกินไป (ระวังไล่ขาย) · 55–70 แข็งแรง · 45–55 ทรงตัว · 30–45 อ่อนแอ
- **Divergence** ตรวจจากจุดสูง/ต่ำเชิงโครงสร้าง แล้วเทียบ RSI สองจุด:
  * 🔻 **Bearish** — ราคาทำจุดสูงใหม่ แต่ RSI อ่อนลง → โมเมนตัมหมด ระวังกลับตัว
  * 🔺 **Bullish** — ราคาทำจุดต่ำใหม่ แต่ RSI แข็งขึ้น → โมเมนตัมฟื้น มองหาจังหวะกลับตัว
- **กรองสัญญาณรบกวน**: ใช้เฉพาะจุดสูง/ต่ำที่ "มีนัยสำคัญ" และห่างกันอย่างน้อย 5 แท่ง พร้อมเลือกจุดที่รุนแรงที่สุดในช่วงนั้น เพื่อไม่ให้การแกว่งเล็ก ๆ สร้างสัญญาณหลอก
- แสดงราคาและค่า RSI ของทั้งสองจุด พร้อมคำอธิบาย เพื่อให้ตรวจสอบย้อนหลังได้

### 10. Market Structure (โครงสร้างราคา) — ข้อ 4
> 💡 ใช้เป็น **ข้อมูลภายใน** (ไม่แสดงแผงแยกบนหน้าเว็บ) — ป้อนทิศทางและความชัดเจนของโครงสร้างให้แผง **ZigZag Pullback** และ **จุดกลับตัวตามเทรน** เพื่อ verdict ที่แม่นยำขึ้น
- อ่านโครงสร้างจากจุดสูง/ต่ำเชิงโครงสร้าง แล้วสรุปแนวโน้มพร้อมป้ายกำกับ:
  | โครงสร้าง | ความหมาย | ป้าย |
  |----------|----------|------|
  | `UP` | จุดสูงขึ้น + จุดต่ำขึ้น (HH + HL) | โครงสร้างขาขึ้น |
  | `DOWN` | จุดสูงลง + จุดต่ำลง (LH + LL) | โครงสร้างขาลง |
  | `BROADENING` | จุดสูงขึ้น แต่จุดต่ำลง | โครงสร้างกว้างตัว (ตลาดยังไม่เลือกทาง) |
  | `CONTRACTING` | จุดสูงลง แต่จุดต่ำขึ้น | โครงสร้างหดตัว (กำลังตัดสินใจ) |
  | `RANGE` | โครงสร้างยังไม่ชัด | เหมาะกับเทรดขอบเขต |
  | `PARTIAL` | จุดสูง/ต่ำยังไม่ครบสองจุด | รอข้อมูลเพิ่ม |
- **BOS (Break of Structure)** — ตรวจเมื่อราคา**ปิด**ทะลุจุดโครงสร้างล่าสุด:
  * 🚀 **BOS ขาขึ้น** — ทะลุจุดสูง → ผู้ซื้อมีอำนาจเหนือ (โครงสร้างเปลี่ยนเป็นขาขึ้น)
  * 💥 **BOS ขาลง** — ทะลุจุดต่ำ → ผู้ขายมีอำนาจเหนือ (โครงสร้างเปลี่ยนเป็นขาลง)
  * แนบ **เวลาที่ราคาทะลุ** เพื่อย้อนตรวจว่าเกิดขึ้นช่วงไหน
- แสดงป้าย HH/HL/LH/LL พร้อมราคาของแต่ละจุดที่ยืนยันแล้ว

### 11. Trading Sessions แบบรับรู้ฤดูกาล (DST-aware) — ปรับปรุงแล้ว
- **ปัญหาเดิม**: ตารางเวลา London/New York ถูกตรึงเป็นค่าคงที่ ทำให้ **เพี้ยนไป 1 ชั่วโมง** ช่วงที่สหรัฐ/ยุโรปเข้าโหมด daylight saving
- **วิธีแก้**: คำนวณจาก **เขตเวลาจริงของแต่ละตลาด** ด้วย `zoneinfo` แล้วแปลงเป็นเวลาไทยอัตโนมัติ
  | Session | ช่วงฤดูร้อน (DST) | ช่วงฤดูหนาว (Standard) |
  |---------|------------------|----------------------|
  | London | 14:00–23:00 | 15:00–00:00 |
  | New York | 19:30–04:00 | 20:30–05:00 |
- แสดง **นับถอยหลังเป็นวินาที** ถึงเวลาเปิด/ปิดแต่ละ session และไฮไลต์ session ที่กำลังเปิดอยู่
- **Overlap London × New York**: ไฮไลต์ช่วงซ้อนทับซึ่งเป็นช่วงที่ทองคำเคลื่อนไหวแรงที่สุด พร้อมคำอธิบายเฉพาะสำหรับ XAUUSD

### 12. ZigZag (Depth 12 / Deviation 5 / Backstep 3) + จุดย่อเข้าตามเทรน — ข้อ 5
- **อัลกอริทึมแบบ MT4/MT5** เชื่อม "สวิงไฮ/สวิงโล" ที่แท้จริงไว้บนกราฟแท่งเทียน:
  | พารามิเตอร์ | ความหมาย |
  |------------|-----------|
  | `Depth = 12` | จุดสุดขั้วต้อง "อยู่ตัว" ครบ 12 แท่งก่อนยืนยันเป็นสวิง (กรองแท่งหลอก) |
  | `Deviation = 5` | ราคาต้องย้อนกลับอย่างน้อย 5 point ก่อนเปลี่ยนขา |
  | `Backstep = 3` | จุดสวิงสองจุดติดกันต้องห่างกัน ≥ 3 แท่ง (จุดที่ถี่เกินถูกยุบรวม) |
- **แปลงตามสัญลักษณ์**: point ของแต่ละสินค้า (ทอง 0.01 / เงิน 0.01 / คู่เงิน 0.00001 / คริปโต 1.0) จึงใช้ป้อนค่าเดียวกันได้ทุกตลาด
- **วาดซ้อนบนกราฟ**: ไลน์สีเหลืองต่อจุดสวิง + หมุดแดง = Swing High, หมุดเขียว = Swing Low (โฮเวอร์ดูราคาได้)
- **แผนเข้าตามเทรนแบบย่อ (Pullback)** ใช้ร่วมกับโครงสร้างราคา:
  * เทรน **UP** → รอย่อลงมาแตะแนวรับ **Higher Low** แล้วเข้าซื้อ, SL ใต้ Low นั้น, TP = Swing High ล่าสุด พร้อม R:R
  * เทรน **DOWN** → รอเด้งขึ้นแตะแนวต้าน **Lower High** แล้วขาย, SL เหนือ High, TP = Swing Low ล่าสุด
  * ถ้าราคาเพิ่งทำจุดสูง/ต่ำใหม่ แผงจะเตือน "อย่าไล่ซื้อ/ไล่ขาย" รอจุดย่อชัดเจนก่อน
- แสดง **Swing High/Swing Low ล่าสุดพร้อมเวลา** เพื่อใช้เทียบจุดวางคำสั่ง

### 13. จุดกลับตัวตามเทรน (Fib + OBV + แท่งกลับตัว + MACD + VWAP) — ข้อ 6
รวม 5 ข้อมูลที่ใช้ยืนยัน "จุดกลับตัวตามเทรน" (Pullback Reversal) ไว้ในแผงเดียว พร้อม verdict สรุป:
- **📐 Fibonacci ย่อจาก ZigZag** — ดึง "ขา ZigZag ล่าสุดที่ตรงกับเทรน" มาเพื่อเปิดโซนย่อ **0.5–0.618** บนกราฟ (แถบสีเหลือง + เส้น 38.2/50/61.8/78.6%) และบอก % ที่ราคาย่อลงมาแล้ว
- **🟢/🔴 OBV + Divergence** — เปรียบเทียบจุดสวิงของราคากับ OBV: ราคาทำจุดต่ำใหม่แต่ OBV แข็งขึ้น = แรงขายหมด (พร้อมเด้ง) / ราคาทำจุดสูงใหม่แต่ OBV อ่อนลง = แรงซื้อหมด (พร้อมย่อ)
- **🕯️ แท่งกลับตัว (Pin Bar / Engulfing)** — ตรวจจับใน 10 แท่งสุดท้าย ใช้เป็น "Trigger" เข้าตอนแท่งยืนยัน ปักหมุดสามเหลี่ยมบนกราฟ พร้อมระบุว่าอยู่ในโซนย่อหรือนอกโซน
- **📊 MACD (12,26,9)** — สถานะ MACD vs Signal + Histogram แนวโน้ม + Golden/Death Cross ล่าสุด (กี่แท่งก่อน) บอกโมเมนตัมกำลังจะหมดหรือมีแรงต่อ
- **🏛️ VWAP** — เส้นมุมมองสถาบัน: ปิดเหนือ VWAP = มุมขึ้น / ปิดใต้ = มุมลง ใช้ยืนยันทิศไม่สวนเทรน
- **verdict ตัดสินใจ**: "🔔 เข้าตามเทรนได้ (Pullback)" เมื่อคะแนนตรง ≥ 3 และไม่มีเงื่อนไขสวนเทรน, "⏳ ใกล้ครบ ยังรอ" เมื่อเข้าใกล้, "🚫 ยังไม่ถึงจุดกลับตัว" เมื่อยังไม่พร้อม
- **หมายเหตุ**: ใช้ OANDA tick volume เป็นน้ำหนัก VWAP/OBV — เป็น proxy ที่นิยมใช้กันมาตรฐานสำหรับการวิเคราะห์ตลาด Forex
- **ใช้งานได้แม้โครงสร้างยังไม่ชัด**: ถ้า Market Structure ยังไม่ยืนยันทิศ แผงจะหาทิศจากสวิง ZigZag / EMA 50–150 ก่อน แล้วปิด verdict แบบอนุรักษ์นิยม ("รอโครงสร้างยืนยันก่อน") แต่ยังให้โซนย่อ/แท่งยืนยันไว้ใช้ประกอบเสมอ; ถ้าแหล่งข้อมูลไม่มี tick volume (คู่เงิน) VWAP จะใช้ equal-weight อัตโนมัติไม่ขึ้น "ข้อมูลไม่พอ"

### สรุปเครื่องมือชุดนี้ทำงานร่วมกันอย่างไร
- **EMA 50/150** = บอกทิศทาง (เทรน)
- **RSI + Divergence** = บอกว่าโมเมนตัมยังเหลือไหม
- **Market Structure + BOS** = บอกว่าใครคุมตลาดอยู่
- **ZigZag 12,5,3** = บอกสวิงไฮ/โลจริงสำหรับหาจุดย่อเข้า + วาง SL/TP
- **Fib + OBV + Pin Bar/Engulfing + MACD + VWAP** = จับจังหวะ "จุดกลับตัวตามเทรน" ให้เข้า/ไม่เข้าแม่นขึ้น
- **DXY** = ดูแรงดอลลาร์ที่กด/หนุนสินทรัพย์
- **S/R + ATR** = หาจุดวาง SL/TP
- **ข่าวแดง + Sessions** = หลีกเลี่ยงช่วงที่ไม่ควรเข้า

> ⚠️ ทุกเครื่องมือเป็น **ตัวช่วยประกอบการตัดสินใจ** ไม่ใช่สัญญาณซื้อขายอัตโนมัติ ควรใช้ควบคู่กับการวิเคราะห์ของตนเองเสมอ

## 🔧 การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

### 1. เวลาข่าวบนเว็บ / LINE ไม่ตรงกับเวลาจริง (เช่น เพี้ยน 3 ชั่วโมง แสดง 16:30 แทน 19:30)

**สาเหตุ**: หน้า Calendar ของ ForexFactory จะเรนเดอร์เวลาเป็น **Timezone ของผู้เข้าชม** ไม่ใช่ New York เสมอไป
- เปิดจากเครื่องในไทย → เวลาจะเป็นเวลาไทย
- เปิดจาก Server ต่างประเทศ (เช่น Streamlit Cloud โซน US) → เวลาจะเป็นโซนอเมริกา
- โค้ดเวอร์ชันเก่าคิดว่าเรนเดอร์เป็นโซน New York เสมอ จึงแปลงเวลาเพี้ยนเป็นค่าคงที่ เช่น 3 ชั่วโมง

**วิธีแก้ (แก้ไว้ในโค้ดแล้ว)**:
1. `news_service.py` → เพิ่ม `_detect_render_timezone()` อ่านโซนเวลาจริงจากหน้าเว็บ (`'timezone': '...'`) แล้วแปลงเป็นเวลาไทยที่ถูกต้อง
2. เพิ่ม `_reconcile_html_times_with_json()` เป็นระบบ "กันเพี้ยน" — หลังดึงตารางมาแล้วจะเทียบเวลากับ **JSON Feed ทางการ** ของ Forex Factory ที่ระบุ UTC Offset ชัดเจน ถ้าเจอว่าเพี้ยนเป็นค่าคงที่ (เช่น 3 ชม.) จะ **ปรับเวลาทั้งตารางให้ตรงจริงอัตโนมัติ** ทั้งในหน้าเว็บและข้อความ LINE

**ถ้าเวลาเพี้ยนบนหน้าเว็บอีก ลองทำตามนี้**:
- กดรีเฟรชหน้าเว็บ (Ctrl+F5) เพื่อให้ Streamlit Cloud โหลดโค้ดเวอร์ชันใหม่
- ถ้ายังเพี้ยน → เข้า **Streamlit Cloud → Deploy → เดิน Deploy ใหม่จาก branch `main`** (บางบัญชีปิด auto-deploy ไว้)
- เช็ค `TIMEZONE=Asia/Bangkok` ใน `.env` / Streamlit Secrets / GitHub Secrets
- ดู log ในไฟล์ `bot.log` — ถ้าเจอข้อความ `พบเวลา HTML ... คลาดเคลื่อน ... กำลังปรับเวลาให้ตรงทั้งหมด` แปลว่าระบบกันเพี้ยนทำงานอยู่

### 2. ข่าว GBP / EUR ถูกส่งเข้า LINE ทั้งที่อยากได้เฉพาะ USD

**สาเหตุ**: ตัวกรองสกุลเงิน `WEEKLY_ALERT_CURRENCIES` อ่านค่าไม่ถูก (เวอร์ชันเก่าอ่านแค่ `.env`, ถ้าค่าว่างจะกลายเป็นส่งทุกสกุล = ALL)

**วิธีแก้ (แก้ไว้ในโค้ดแล้ว)**:
- `config.py` → `WEEKLY_ALERT_CURRENCIES` อ่านผ่าน `_get_secret` แล้ว (รองรับทั้ง `.env`, Streamlit Secrets, GitHub Secrets)
- `news_service.py` → ถ้าตัวแปรว่าง/ไม่ตั้งค่า จะใช้ค่าเริ่มต้น `USD` (ไม่ใช่ส่งทุกสกุลเงินอีกต่อไป)
- ตั้งค่า `WEEKLY_ALERT_CURRENCIES=USD` (หรือ `USD,EUR` ถ้าต้องการหลายสกุล, `ALL` = ทุกสกุล) ใน:
  - `.env` (สำหรับรันบนเครื่องตัวเอง)
  - Streamlit Secrets (สำหรับหน้าเว็บ Dashboard)
  - GitHub Actions Secrets (สำหรับ Workflow ส่งข่าวอัตโนมัติวันจันทร์)
- ข้อความ LINE จะแสดงหัวข้อ `💱 สกุลเงินที่ติดตาม: USD` เพื่อให้เข้าใจชัดเจนว่ากรองสกุลไหน

**เช็คด่วน**: กดปุ่ม `📢 ส่งสรุปข่าวแดงสัปดาห์นี้เข้า LINE ทันที` ที่หน้าเว็บ → สรุปข่าวควรมีเฉพาะสกุลเงินที่ตั้งค่าไว้ และเวลาเป็นเวลาไทยที่ถูกต้อง

### 3. RSI / DXY / โครงสร้างราคา ขึ้นว่า "ข้อมูลไม่พอ" (Too few data)

**สาเหตุ**: ต้องมีแท่งเทียนมากพอสำหรับคำนวณ ได้แก่ RSI ต้อง > 15 แท่ง, Divergence/โครงสร้างราคาต้องมีจุดสูง–ต่ำครบ 2 จุด, DXY ต้องมีข้อมูลทับซ้อนกับสินทรัพย์หลักพอ

**วิธีแก้**:
- ถ้าเพิ่งเปิดหน้าเว็บ ให้กดรีเฟรชอีกครั้ง (ข้อมูลถูก cache แล้วจะเติมเอง)
- ลด timeframe ลงมา (เช่น เปลี่ยนจาก D1 เป็น H1 หรือ M15) จะได้แท่งเยอะกว่าในจำนวนวันเท่ากัน
- ตรวจว่าโควตา API ยังเหลือ — ถ้าหมดระบบจะแสดง "ข้อมูลไม่พอ" แทนตัวเลขผิด โดยดูโควตาที่ [twelvedata.com/dashboard](https://twelvedata.com/dashboard)
- ถ้าเป็นคู่เงินใหม่ที่ไม่มีข้อมูลเทียบ แผง Correlation จะขึ้น "ข้อมูลไม่พอ" ตามปกติ ไม่ใช่ข้อผิดพลาด

### 4. Price Alert ข้อมูลหายหลังรีสตาร์ท

**สาเหตุ**: ข้อมูลเก็บในโฟลเดอร์ `state/` ซึ่งเป็น **พื้นที่ชั่วคราวของ Streamlit Cloud** (รีสตาร์ทแล้วของเก่าจะหาย)

**วิธีแก้**:
- ถ้าต้องการเก็บถาวร ให้ย้ายการเขียนไฟล์ไปใช้ฐานข้อมูลภายนอก (ดูหัวข้อ Roadmap ข้อ 7)
- ถ้าต้องการสำเนาไว้ กดดาวน์โหลดไฟล์ `state/price_alert.json` เก็บไว้ก่อนรีสตาร์ท

## 🧪 การทดสอบและคุณภาพ (Testing & Quality)

ฟีเจอร์วิเคราะห์ทุกตัวผ่านการทดสอบด้วยข้อมูลตัวอย่างที่ควบคุมค่าได้ ก่อนนำไปใช้งานจริง:

- **RSI**: เทียบกับสูตร Wilder มาตรฐานทุกแท่ง (ต่างกัน 0.00) และตรวจขอบเขต 0–100 ในกรณีขาขึ้น/ขาลง/ราคานิ่ง
- **Divergence**: ตรวจกับตรรกะอ้างอิงที่เขียนแยกอิสระ บนกรณีขาขึ้น ขาลง เส้นราบ และข้อมูลสุ่ม
- **Market Structure**: ทดสอบ HH+HL, LH+LL, BOS ขาขึ้น/ขาลง รวมถึงข้อมูลผิดรูปแบบ (คอลัมน์ไม่ครบ, ข้อมูลสั้น)
- **ทุกฟีเจอร์**: มีการป้องกัน error เมื่อผู้ให้บริการราคาล้มเหลวหรือข้อมูลไม่พอ — หน้าเว็บจะแสดง "ข้อมูลไม่พอ" แทนการพัง
